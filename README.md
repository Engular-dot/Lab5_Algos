# Бинарное дерево поиска (BST)

## Описание
Реализация бинарного дерева поиска для хранения целых чисел. Каждый узел содержит значение и ссылки на левого и правого потомка. Свойство BST: для любого узла все элементы в левом поддереве меньше его значения, а в правом - больше. Дубликаты не добавляются.

## Работа
1. insert(root, value) - Вставляет значение в дерево поиска.

Параметры:

root: корень дерева (может быть None)

value: вставляемое целое число

Возвращает: корень дерева

Алгоритмическая сложность:

В среднем: O(log n)

В худшем случае: O(n) (когда дерево вырождается в линейный список)

Пространственная сложность:

O(log n) в среднем (глубина рекурсии)

O(n) в худшем случае (глубина рекурсии для вырожденного дерева)

Примечание: Рекурсивная реализация использует стек вызовов. Для n элементов глубина рекурсии равна высоте дерева.


2. search(root, target) - Выполняет поиск значения в дереве.

Параметры:

root: корень дерева

target: искомое значение

Возвращает: True если значение найдено, иначе False

Алгоритмическая сложность:

В среднем: O(log n)

В худшем случае: O(n)

Пространственная сложность:

O(log n) в среднем (глубина рекурсии)

O(n) в худшем случае

3. inorder(root, result=None) - Выполняет симметричный обход дерева (левое поддерево → корень → правое поддерево).

Параметры:

root: корень дерева

result: список для накопления результатов (опционально)

Возвращает: список значений в порядке возрастания

Алгоритмическая сложность:

O(n) - всегда, так как необходимо посетить каждый узел ровно один раз

Пространственная сложность:

O(n) для хранения результирующего списка + O(h) для стека рекурсии

4. get_sorted_list(root) - Возвращает отсортированный список всех элементов дерева.

Параметры:

root: корень дерева

Возвращает: список целых чисел в порядке возрастания

Алгоритмическая сложность:

O(n) - обход всех узлов

Пространственная сложность:

O(n) для хранения результирующего списка

O(log n) дополнительно для стека рекурсии (в среднем)
